# Dragonite

Dragonite is **closed source** software. We are releasing compiled binaries to the community with no plans to release the source code. Currently this feels like the correct approach to make sure we are able to maintain this project. If you do not like this decision you are welcome to continue using other alternatives in the market.

**Dragonite** is our backend controller. In short, Dragonite tells the game which accounts to log in with, where to go, and what action you want completed.

**Dragonite-Admin** is a web front end to interact with Dragonite. Generally speaking Dragonite Admin is a proxy service to allow Admin users to interact with backend Dragonite server. With this service you can configure your Areas, Accounts, Routes and schedules. Both are available from the [Dragonite-Public](https://github.com/UnownHash/Dragonite-Public) repository.

## Features

1. [Pokemon mode](/docs/dragonite/modes#pokémon) with shared encounter cache - only one worker will encounter a pokemon; including lure encounters and knowledge of weather changes
1. [Fort inspection](/docs/dragonite/modes#fort-inspection): fort names, gym defenders, exact lure times and showcases
1. Wide area raid scanner, with priority jumping for egg hatches
1. [Quest scanning](/docs/dragonite/modes#quest) driven by the [scheduler](/docs/dragonite/scheduler), timezone aware, with automatic rescans when quests change (eg for an event)
1. [Quest quarantine](/docs/dragonite/accounts-auth#quest-quarantine): only accounts that can return real quest data are used for quests
1. [Rare Pokemon mode](/docs/dragonite/modes#rare-pokémon): dedicated workers hunt the rarest spawns in each area
1. [Invasion mode](/docs/dragonite/modes#invasion): Rocket lineup detection
1. [Scout](/docs/dragonite/modes#scout) support for scan on demand from ReactMap
1. [Scheduler](/docs/dragonite/scheduler) for worker scaling, pausing, route modes and route recalculation
1. Built in [level mode](/docs/dragonite/modes#level) that is fast
1. Defaults to keep your accounts safe, with [background token handling](/docs/dragonite/accounts-auth#tokens) for PTC and NK accounts
1. Built in proxy support (ie it calls the login through the proxy for you no need for haproxy/squid)
1. Koji integration for hands free route creation
1. Low CPU usage, highly scalable, can run 1000+ workers in a single installation
1. gRPC raw send to Golbat, can send raws to multiple destinations
1. Built in Prometheus stats, and raw stats table for detailed performance measurements
1. [API](/docs/dragonite/api) for everything; and a beautiful admin tool
