# Statistics

Golbat comes with basic database statistics built in. These tables are named with the `_stats` suffix. With these tables you can use raw SQL queries or hook into a third party visualization tool to visualize the data that Golbat is parsing.

[Blissey](/docs/other/blissey) and our [Prometheus](/docs/other/prometheus) integration can be used to get started on visualizing the data.

## Built-in statistic tables

| Table name          |
| ------------------- |
| raid_stats          |
| pokemon_stats       |
| pokemon_iv_stats    |
| pokemon_area_stats  |
| pokemon_hundo_stats |
| pokemon_nundo_stats |
| quest_stats         |
| invasion_stats      |
| pokemon_shiny_stats |

`pokemon_area_stats` groups Pokémon by your [geofences](/docs/golbat/features#geofences). Pokémon outside all geofences, or all Pokémon when none are configured, are counted under the area `unmatched`.

## Writing and cleanup

How often each table is written is set in [`[stats_intervals]`](/docs/golbat/config#stats-intervals-section).

Old rows are **not removed by default**. Set `cleanup.stats = true` to delete rows older than `cleanup.stats_days` (default 7) from `pokemon_stats`, `pokemon_shiny_stats`, `pokemon_iv_stats`, `pokemon_hundo_stats`, `pokemon_nundo_stats`, `invasion_stats`, `quest_stats` and `raid_stats`. `pokemon_area_stats` is pruned separately on a fixed schedule.
