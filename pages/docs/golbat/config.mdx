# Golbat Configuration

Golbat reads its settings from a TOML file. Every key has a built-in default, so you only need to set what you want to change. Start from [`config.toml.example`](https://github.com/UnownHash/Golbat/blob/main/config.toml.example) in the repository and add keys from this page as needed.

The **Default** column below is the value Golbat uses when the key is missing from your file. The example config sometimes sets a different value; where that matters it is called out.

## Loading the config

- Golbat reads `config.toml` from its working directory. Use `-c` / `--config` to load a different file:
  ```bash
  ./golbat --config /etc/golbat/config.toml
  ```
  The default `config.toml` is optional. A file passed with `--config` must exist.
- **Environment variables** override the file. The name is `GOLBAT.` followed by the upper-cased key path, for example `GOLBAT.DATABASE.ADDRESS` or `GOLBAT.CLEANUP.STATION_BATTLES`. Array-of-table sections take an index: `GOLBAT.WEBHOOKS.0.URL`, `GOLBAT.SCAN_RULES.1.CONTEXT`. See [`docker-compose.yml.example`](https://github.com/UnownHash/Golbat/blob/main/docker-compose.yml.example) for a full example.

## Root section

```toml
port = 9001
#grpc_port = 50001
raw_bearer = ""
api_secret = "golbat"
pokemon_memory_only = true
```

| Key | Default | Description |
| :-- | :-- | :-- |
| `port` | `0` | HTTP listening port for `/raw` and the API. The example uses `9001`. |
| `grpc_port` | `0` (off) | gRPC listening port. Serves both raw ingest and the [gRPC query API](/docs/golbat/api#grpc-api). |
| `raw_bearer` | `""` | When set, `/raw` requires `Authorization: Bearer <raw_bearer>`. |
| `api_secret` | `""` | When set, API calls require the `X-Golbat-Secret` header (gRPC: `x-golbat-secret` metadata). Empty disables the check. |
| `api_docs` | `true` | Serves interactive API docs at `/docs` plus `/openapi.json` and `/schemas`. These never require the API secret. |
| `pokemon_memory_only` | `false` | Stop writing Pokémon to the `pokemon` table. Golbat always tracks Pokémon in memory and serves them over the API, so most setups enable this (the example config does). |
| `preserve_pokemon` | `false` | With `pokemon_memory_only`, save the in-memory Pokémon to the database on shutdown and restore them on startup. |
| `pokemon_internal_to_db` | `false` | Write the internal scan-history blob to the database for encountered Pokémon. |
| `store_username` | `false` | Store the reporting account on the Pokémon row. When off, Pokémon webhooks report the account that triggered the save, and saves without one carry `"username": null`. |
| `preload` | `false` | Load forts, stations and recent spawnpoints into cache at startup. Faster first responses, longer startup. |
| `fort_in_memory` | `false` | Keep forts in an in-memory spatial index. Required for the fort `scan` and `available` [API endpoints](/docs/golbat/api) (they return 503 without it). Experimental. |

## Koji section

```toml
[koji]
url = "http://{koji_url}/api/v1/geofence/feature-collection/{golbat_project}"
bearer_token = "secret"
```

| Key | Default | Description |
| :-- | :-- | :-- |
| `url` | `""` | Koji feature-collection endpoint for the geofences Golbat uses for area stats, webhook areas and scan rules. |
| `bearer_token` | `""` | Koji bearer token. |

Without a Koji URL, Golbat reads `geojson/geofence.json` instead. Koji results are cached in `cache/koji_geofence.json` and used if Koji is unreachable at startup. Reload geofences without restarting via [`/api/reload-geojson`](/docs/golbat/api#admin).

## Cleanup section

```toml
[cleanup]
pokemon = true
incidents = true
station_battles = true
quests = true
tappables = true
stats = true
stats_days = 7
device_hours = 24
```

| Key | Default | Description |
| :-- | :-- | :-- |
| `pokemon` | `true` | Remove expired Pokémon from the `pokemon` table (only relevant when Pokémon are written to the database). |
| `incidents` | `true` | Remove expired invasions. |
| `station_battles` | `true` | Remove expired max battles. |
| `quests` | `true` | Remove expired quests. |
| `tappables` | `true` | Remove expired tappables. |
| `stats` | `false` | Prune [statistics tables](/docs/golbat/stats) older than `stats_days`. The example config enables it. |
| `stats_days` | `7` | Days to keep in `pokemon_stats`, `pokemon_shiny_stats`, `pokemon_iv_stats`, `pokemon_hundo_stats`, `pokemon_nundo_stats`, `invasion_stats`, `quest_stats` and `raid_stats`. |
| `device_hours` | `24` | Forget devices not seen for this many hours. |
| `forts_stale_threshold` | `3600` | Seconds before a fort missing from cell scans is considered stale and removed. |
| `forts_min_miss_count` | `1` | Consecutive cell scans a fort must be missing from before it can be considered stale. |

## PvP section

```toml
[pvp]
enabled = true
include_hundos_under_cap = false
level_caps = [50, 51]
#ranking_comparator = "prefer_higher_cp"
```

| Key | Default | Description |
| :-- | :-- | :-- |
| `enabled` | `false` | Calculate PvP rankings for encountered Pokémon. |
| `include_hundos_under_cap` | `false` | Include 100% IV Pokémon below the level cap in rankings. |
| `level_caps` | `[50, 51]` | Level caps used in rankings. |
| `ranking_comparator` | `""` | Empty uses tied rankings (1, 1, 3, 4). `prefer_higher_cp` or `prefer_lower_cp` break ties (1, 2, 3, 4), matching external calculators. |

## Weather section

```toml
[weather]
proactive_iv_switching = true
proactive_iv_switching_to_db = false
```

| Key | Default | Description |
| :-- | :-- | :-- |
| `proactive_iv_switching` | `true` | When a cell's weather changes, update the IVs of Pokémon in that cell for the new boost state without waiting for a rescan. |
| `proactive_iv_switching_to_db` | `false` | Also write those changes to the database. |

Both can be overridden per area or scanner mode with [scan rules](#scan-rules).

## Scan rules

**⭐ Advanced option ⭐**

Scan rules change which game objects Golbat processes, either globally, for specific areas, or for specific scanner modes (`context`). Rules are checked in order and **the first matching rule applies**. Keys you leave out keep their normal behaviour.

| Key | Description |
| :-- | :-- |
| `areas` | Geofence names the rule applies to (`"Parent/Name"`, `"Parent/*"` or `"Name"`). |
| `context` | Scanner modes the rule applies to. Dragonite sends `Fort`, `Pokemon`, `Quest`, `Scout` and `RarePokemon`. Matching ignores case. |
| `pokemon` | Any Pokémon processing (also disables spawnpoints). |
| `wild_pokemon` | Wild Pokémon from the GMO. |
| `nearby_pokemon` | Nearby Pokémon at a pokestop. |
| `nearby_cell_pokemon` | Nearby Pokémon without a pokestop, placed at the S2 cell centre. **Off unless a rule sets it to `true`**; `nearby_pokemon` does not enable it. |
| `weather` | Weather from the GMO. |
| `cells` | Cell updates. Disabling this also disables automatic removal of stale forts. |
| `pokestops` | Pokestops from the GMO. |
| `gyms` | Gyms from the GMO. |
| `stations` | Power spot stations from the GMO. |
| `tappables` | Tappables. |
| `proactive_iv_switching` | Override the `[weather]` setting for matching data. |
| `proactive_iv_switching_to_db` | Override the `[weather]` setting for matching data. |

A global rule: drop Pokémon without IVs from the GMO and nearby Pokémon.

```toml
[[scan_rules]]
wild_pokemon = false
nearby_pokemon = false
```

Per area and per mode: the main area skips nearby Pokémon, everything from Scout mode is processed, and no Pokémon are processed anywhere else.

```toml
[[scan_rules]]
areas = ["MainArea"]
nearby_pokemon = false

[[scan_rules]]
context = ["Scout"]

[[scan_rules]]
pokemon = false
```

Per mode only:

```toml
[[scan_rules]]
context = ["Quest"]

[[scan_rules]]
context = ["Fort"]
pokemon = false

[[scan_rules]]
context = ["Pokemon"]
nearby_pokemon = false
```

<Callout type="info">
  Under heavy load, disabling `nearby_pokemon` saves a lot of processing.
</Callout>

## Webhooks section

Add one `[[webhooks]]` block per destination.

```toml
[[webhooks]]
url = "http://localhost:4201"
types = ["pokemon_iv", "raid", "quest"]

[[webhooks]]
url = "http://localhost:4202"
types = ["raid"]
areas = ["London/*", "*/Harrow"]
exclude_areas = ["London/Westminster"]
headers = ["X-Poracle-Secret:abc"]
```

| Key | Default | Description |
| :-- | :-- | :-- |
| `url` | | Destination URL. |
| `types` | all | Webhook types to send: `pokemon`, `pokemon_iv`, `pokemon_no_iv`, `gym`, `raid`, `quest`, `pokestop`, `invasion`, `weather`, `fort_update`, `max_battle`, `tappable`, `raid_lobby`, `max_battle_lobby`. |
| `areas` | all | Only send messages from these areas. |
| `exclude_areas` | none | Never send messages from these areas. Exclusion wins over `areas`. |
| `headers` | none | Extra HTTP headers as `"Name:value"` strings. The value cannot contain another `:`. |

`pokemon` covers both `pokemon_iv` (all three IVs known) and `pokemon_no_iv` (IVs not known yet). See [Webhooks](/docs/golbat/webhooks) for payloads and when each type fires.

| Key | Default | Description |

## Tuning section

**⭐ Advanced option ⭐** The defaults suit most installs.

| Key | Default | Description |
| :-- | :-- | :-- |
| `max_pokemon_results` | `3000` | Maximum Pokémon returned per API scan. |
| `max_pokemon_distance` | `100` | Maximum diagonal of a Pokémon scan area, in km. |
| `max_fort_results` | `9000` | Maximum gyms, pokestops or stations returned per fort scan. |
| `max_tappable_results` | `9000` | Maximum tappables returned per scan. |
| `extended_timeout` | `false` | Raise the per-proto processing timeout from 5 s to 30 s. |
| `reduce_updates` | `false` | Write unchanged forts every 12 hours instead of every 15 minutes, and spawnpoint `last_seen` every 12 hours instead of 6. Reduces database load. |
| `max_concurrent_proactive_iv_switch` | `6` | Parallel cells processed on weather changes. |
| `write_behind_startup_delay` | `120` | Seconds after startup during which database writes are only queued. |
| `write_behind_worker_count` | `16` | Maximum parallel batch writers. Raise only if write latency grows in steady state. |
| `write_behind_batch_size` | `50` | Rows per batch write. |
| `write_behind_batch_timeout` | `100` | Milliseconds to wait before flushing a partial batch. |
| `raw_processing_concurrency` | `0` | Concurrent raw decoders. `0` = 4× CPUs (max 96), `-1` = unlimited. |
| `raw_processing_queue_factor` | `0` | Decode queue size as a multiple of the concurrency limit. `0` = 32. When full, requests are dropped. |
| `s2_cell_lookup` | `false` | Precompute geofence lookups per S2 cell. About 7× faster matching for about 60× the geofence file size in memory. |
| `slow_db_query_ms` | `0` | Log `[DB_SLOW]` for queries slower than this. `0` = 1000 ms, `-1` = off. |
| `gogc_percent` | `0` | Go GC target (Go default 100). Higher values use more memory and less CPU. `0` leaves Go's default. |
| `go_mem_limit_mib` | `0` | Soft memory limit in MiB. `0` = off. Useful as a backstop when raising `gogc_percent`. |
| `profile_routes` | `false` | Enable `/debug/pprof` endpoints. |
| `profile_contention` | `false` | Collect block and mutex profiles. Has a performance cost. |
